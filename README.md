# Akshit Patel — Personal Portfolio

A responsive, single-page personal portfolio built with plain HTML, CSS and JavaScript. It is intentionally dependency-free and can be published directly with GitHub Pages.

## 1. Personalise before publishing

Open `index.html` and update:
- `YOUR_EMAIL@example.com` with your real email address.
- The LinkedIn URL (`https://www.linkedin.com/`) with your profile URL.
- The GitHub URL (`https://github.com/`) with your GitHub profile URL.

Review the About and project descriptions. Keep project statuses accurate; change “concept”, “in development” or “academic project” only when appropriate.

## 2. Preview on your computer

Open `index.html` in a browser. You can also use the VS Code Live Server extension for a local preview.

## 3. Publish with GitHub Pages

1. Create a public repository named exactly `YOUR-GITHUB-USERNAME.github.io`.
2. Upload `index.html`, `styles.css`, `script.js`, and this README to the repository root (not inside another folder).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait a few minutes. Your site will be at `https://YOUR-GITHUB-USERNAME.github.io/`.

## Notes
- No paid hosting or build process is required.
- Google Fonts are loaded from Google Fonts; if unavailable, the site uses fallback fonts.
- Replace placeholder social links and email before sharing the site publicly.
